# Hybrid Recommendation Test Checklist

- [ ] Candidate creates a preference with Java and Spring skills.
- [ ] Create multiple published jobs: Java Developer, React Developer and DevOps Engineer.
- [ ] Candidate views several React jobs.
- [ ] Candidate clicks several React jobs.
- [ ] Candidate saves several React jobs.
- [ ] Candidate tracks search keyword `react developer`.
- [ ] Candidate calls `GET /api/v1/candidate/jobs/recommended`.
- [ ] React jobs have increased `behaviorScore`.
- [ ] Create another user with skills similar to the candidate.
- [ ] Similar user applies to a Java job.
- [ ] Similar user saves a Java job.
- [ ] Candidate calls recommended jobs again.
- [ ] Java jobs have non-zero `collaborativeScore`.
- [ ] Candidate applies to one recommended job.
- [ ] Candidate calls recommended jobs again.
- [ ] Applied job no longer appears.
- [ ] Response includes `contentScore`, `behaviorScore`, `collaborativeScore` and `hybridScore`.
- [ ] Response includes correct `reasonCodes`.
- [ ] Pagination returns the expected page size and total metadata.
- [ ] Candidate cannot request another user's recommendation data because no API accepts `userId`.
- [ ] Unauthenticated requests to `/api/v1/candidate/**` return unauthorized.
